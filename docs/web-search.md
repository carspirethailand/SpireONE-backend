# ค้นเว็บของ Cendon AI (web-search.mjs)

Cendon AI ค้นเว็บผ่าน **Tavily · Exa · Firecrawl เท่านั้น** — เลิกใช้ Google Search ของ Gemini (grounding), DuckDuckGo, Bing RSS, Google News RSS, Brave และ Wikipedia ในการค้นของ AI แล้ว
ขั้นตอน: ด่านความเป็นส่วนตัว → ค้นตามประเภทคำถาม (เจ้าเดียวหรือหลายเจ้าพร้อมกัน) → รวมผล ตัดซ้ำ จัดอันดับ → แนบให้โมเดลเป็นหลักฐาน

## เปิดใช้

```
wrangler secret put TAVILY_API_KEY
wrangler secret put EXA_API_KEY
wrangler secret put FIRECRAWL_API_KEY
```

**ไม่มีคีย์ = AI ค้นเว็บไม่ได้เลย** (ไม่มีทางสำรองแบบเก่าแล้ว) — แชตจะบอกผู้ใช้ตรง ๆ ว่ายังยืนยันข้อมูลล่าสุดไม่ได้ ห้ามเดาตัวเลขหรือข่าว
หน้าแอดมิน › ตรวจระบบ AI (`/api/admin/diag`) ยิงคำค้นทดสอบทีละเจ้าและบอกว่าเจ้าไหนผ่าน ใช้เวลาเท่าไร ได้กี่ผล

## ประเภทการค้น → เจ้าที่ใช้ (`SEARCH_ROUTES`)

| ประเภท | คำถามแบบไหน (`searchKind`) | เจ้า (ตามลำดับ) | วิธีค้น |
|---|---|---|---|
| `general` | ทั่วไป วิธีทำ สถานที่ ภาษี/กฎหมาย | Tavily → Exa → Firecrawl | `fast` เจ้าแรกที่ได้ผลจบ |
| `price` | ราคา ค่าแรง ค่าอะไหล่ ประกัน มือสอง | Tavily (country=thailand) → Firecrawl (location TH) → Exa | `fast` |
| `news` | ข่าว เปิดตัว ล่าสุด | Tavily topic=news + Exa category=news | `balanced` สองเจ้าพร้อมกัน 7 วัน |
| `spec` | สเปก ความจุ คู่มือ เรียกคืน อาการ/สาเหตุ รหัสปัญหา | Exa + Tavily | `balanced` สองเจ้าพร้อมกัน |
| `research` | ต้องอ่านเนื้อหาในหน้า (เอกสารผู้ผลิต) | Exa text + Firecrawl markdown | `balanced` พร้อมเนื้อหาเต็มหน้า |

ลำดับมาจากจุดเด่นของแต่ละเจ้าตามเอกสาร ยังไม่ใช่ผลวัดจริง — ตั้งคีย์แล้วรัน `POST /api/admin/search-bench` แล้วปรับลำดับได้ด้วย
ตัวแปร `SEARCH_ROUTES` (JSON เช่น `{"spec":"tavily,exa"}`) โดยไม่ต้องแก้โค้ด · แถบความละเอียดในแชต: เร็ว = `fast` · ละเอียดสุด = `deep` (ทุกเจ้าพร้อมเนื้อหา)

## ใช้ที่ไหน

| จุด | ฟังก์ชัน | ประเภท |
|---|---|---|
| แชตในแอป (สตรีม · ตอบทีเดียว · ทำต่อเบื้องหลัง) · แชตใน LINE · ReAct สำรอง | `executeWebSearchTool` (worker.js) → `searchForChat` | เดาจากคำถาม · เติมยี่ห้อ/รุ่น/ปีรถที่กำลังคุยถ้าคำถามไม่ได้บอก |
| ทางสำรอง Groq/OpenRouter | `webSearch` / `executeSearchInternal` (fastai.js) | เดาจากคำถาม |
| `/api/ai` แบบแชต · รายการอะไหล่ตรงรุ่น · ร้านค้า | `callGemini({ search: { q, kind } })` | ระบุเอง (อะไหล่/ร้านค้า = `price`) |
| ฟังเสียงเครื่องยนต์ · `/api/ai/research` (เครื่องมือ web_search ตอนโทร) | `publicResearch` (vehicle-research.mjs) | `research` จำกัดเฉพาะเว็บผู้ผลิตในรายชื่อ |
| คลังสเปกรถ | `collectSpecDocuments` (spec-web.js) | `spec` — ได้แค่ลิงก์ แล้วต้องผ่านรายชื่อเว็บ robots.txt และการตรวจรุ่น/ปีเหมือนลิงก์อื่น |
| นิตยสาร (เมื่อดึงฟีดไม่ได้เลย) | `aiSearchNews` (news.js) | `news` 3 วัน — ข่าวมีลิงก์ต้นทางจริง |

Gemini ไม่ได้รับเครื่องมือค้นเว็บอีกแล้ว ผลค้นแนบไปใน system ก่อนเรียก Gemini ครั้งเดียว ในแชตใช้ `sourcesBlock(r, { cite: false })` เพราะหน้าแอปยังไม่แสดงการ์ดแหล่งที่มา (ไม่ให้เลข `[n]` ดิบโผล่ในคำตอบ)

## ความเป็นส่วนตัว

- คำค้นของแชต/การโทรต้องผ่าน `publicQuery` ก่อนเสมอ — ยาวเกิน 240 ตัวอักษร หรือมีเบอร์ อีเมล ลิงก์ เลขตัวถัง ทะเบียน พิกัด คีย์ ฯลฯ = ไม่ค้นเลย
- `scrubQuery` ตัดข้อมูลส่วนตัวที่หลุดมาอีกชั้นก่อนส่งทุกครั้ง ไม่มีชื่อหรือบัญชีผู้ใช้ในคำค้น
- ข้อความจากเว็บถูกบอกโมเดลว่าเป็นหลักฐาน ไม่ใช่คำสั่ง (กัน prompt injection) · เรียก API ด้วย `redirect: 'manual'` แล้วถือว่า 3xx คือค้นไม่ผ่าน (ไม่ตาม redirect ที่พาคีย์ไปเว็บอื่น · ห้ามใช้ `redirect: 'error'` — Workers โยน TypeError ทันทีก่อนส่งคำขอ ทุกเจ้าจะล้มใน 0 ms) และจำกัดขนาดคำตอบ
- ผู้ให้บริการทั้งสามอยู่ในตารางผู้ประมวลผลของหน้า /privacy

เจ้าที่ติดโควตา (429/402) พัก 5 นาที · ล่ม/ช้าเกิน พัก 1 นาที แล้วไปเจ้าถัดไป

## ทดสอบเทียบเจ้า

- ในเครื่อง: `TAVILY_API_KEY=… EXA_API_KEY=… FIRECRAWL_API_KEY=… node tools/search-bench.mjs [--mode=deep] [--limit=12]`
- ในระบบจริง (ใช้คีย์ใน Worker ไม่ต้องคัดลอกคีย์ออกมา): แอดมินเรียก
  - `GET /api/admin/search-status` — เจ้าที่ตั้งคีย์ไว้ ลำดับ และเจ้าที่แต่ละประเภทจะใช้
  - `POST /api/admin/search-bench {"mode":"balanced","limit":12}` — ตารางเทียบ (สำเร็จ, p50/p95, ความเกี่ยวข้อง, ภาษาไทย, แหล่งน่าเชื่อถือ, วันที่, ต้นทุน, ผลซ้ำระหว่างเจ้า)
  - `POST /api/admin/search-try {"q":"…","mode":"balanced"}` — ลองคำค้นเดียว

ชุดคำค้น 12 ข้อ (`BENCH_QUERIES`) ครอบคลุม: เรียกคืนรถ ราคาซ่อม อาการ EV ขั้นตอนราชการ สเปกภาษาอังกฤษ ข่าว 7 วัน กระทู้ต่างประเทศ ความรู้ทั่วไป พ.ร.บ. และค้นหาศูนย์บริการในพื้นที่
ค่า `relevant` วัดจากคำที่คาดว่าคำตอบที่ดีต้องมี — เป็นตัวชี้วัดคร่าว ๆ ยังไม่ใช่การให้คนหรือโมเดลตัดสินคุณภาพคำตอบ
